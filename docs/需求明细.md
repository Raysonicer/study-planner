# 学习任务计划系统 · 需求明细 v1.0

- 日期：2026-10-15
- 关联文档：`落地方案.md`（口径与决策以方案为准）· `openapi.yaml`（接口契约）· `sql/000001_init.*.sql`（数据模型）
- 优先级：P0 = 首版（M0-M6）；P1 = 第二版；P2 = 远期
- 状态语义：
  - 任务：todo / doing / done
  - 日目标：active → 打卡后 done；当日结束未打卡在展示层标「未达成」
  - 周目标：active / done / archived；打卡型达成率 = 打卡天数 / checkin_days
- 编号：G=目标，T=任务，B=日程，S=统计，R=复盘，SYS=系统

## 1. 学习目标（G）

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| G-01 | 创建日目标：标题必填，绑定日期（默认今天），备注可选 | 保存后出现在对应日期的目标列表 |
| G-02 | 编辑日目标（标题/日期/备注） | 修改后列表与统计即时一致 |
| G-03 | 删除日目标（连带打卡记录，二次确认） | 删除后不再计入任何统计口径 |
| G-04 | 日目标打卡完成/撤销 | 打卡写 goal_checkins 事件；撤销回 active；今日面板联动 |
| G-05 | 日目标按日期浏览；已过当日未打卡显示「未达成」 | 徽章展示正确 |
| G-06 | 创建周目标：一次性型/每日打卡型（应打卡天数 1-7，默认 5）；绑定周默认本周 | 两种模式可正确区分与编辑 |
| G-07 | 周目标编辑/删除/归档 | 归档默认隐藏、历史统计保留 |
| G-08 | 一次性型周目标完成/撤销 | 完成记 completed_at，撤销还原 |
| G-09 | 打卡型周目标按日打卡/撤销；打卡日期必须落在绑定周内 | 跨周打卡被拒绝并提示 |
| G-10 | 周目标达成率实时计算（打卡天数/应打卡天数） | 与口径冻结表一致 |
| G-11 | 任务关联目标（1 任务 ≤ 1 目标）；目标详情显示关联任务完成率为参考口径 | 任务完成/重开时参考口径联动 |
| G-12 | 目标同列表排序（上移/下移） | 刷新后顺序保持 |

## 2. 任务分解（T）

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| T-01 | 创建任务：标题必填；备注(MD)/优先级 0-3/截止日/预估时长/标签/父任务/关联目标可选 | 创建后进入正确层级位置 |
| T-02 | 编辑任务全部字段 | 保存即时刷新 |
| T-03 | 删除任务：递归删除子任务；时间块关联置空；二次确认 | 子任务、事件、块关联处理正确 |
| T-04 | 子任务树任意层级；默认展示两级、可展开 | 缩进与展开正确，同级排序独立 |
| T-05 | 批量分解：粘贴多行文本一键生成 N 个子任务（自动去空行） | 行数=子任务数，标题逐行一致 |
| T-06 | 状态流转 todo→doing→done；打勾完成/撤销 | 完成/重开写 task_events；撤销后历史统计还原 |
| T-07 | 父任务进度 = 已完成直接子任务/直接子任务总数 | 只统计直接子级；进度条显示 |
| T-08 | 全部子任务完成时提示一键完成父任务；设置 auto_complete_parent 默认关 | 开启后自动完成并写事件 |
| T-09 | 组合筛选：状态/目标/标签/截止日范围/关键词 | 组合条件结果正确 |
| T-10 | 同层级手动拖拽排序 | 顺序持久化 |
| T-11 | 逾期标识：due_date < 今日且未完成标红 | 列表与面板一致 |

## 3. 日程管理（B）

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| B-01 | 日视图 24h 时间轴、半小时刻度、当前时间指示线 | 打开自动滚动至当前时间 |
| B-02 | 点击空白创建时间块（默认 1h）；可先选时段再创建 | 块出现在正确时间段 |
| B-03 | 编辑/删除时间块 | 即时刷新 |
| B-04 | 块字段：起止时间/标题/颜色/关联任务/备注 | 全部可编辑 |
| B-05 | 校验 end_min > start_min；允许重叠但重叠区域视觉提示 | 非法输入被阻止 |
| B-06 | 拖动平移时间块（保持时长） | 平移后起止时间持久化 |
| B-07 | 任务侧栏拖入时间轴生成块（时长=任务预估时长或默认 1h） | 生成块自动关联任务 |
| B-08 | 关联任务完成 → 时间块高亮 | 完成后块样式联动 |
| B-09 | 周视图 7 列只读概览，点击跳转当日 | 跨天块显示正确 |

## 4. 统计（S）

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| S-01 | 今日面板：任务完成率/目标达成率/日程占用/逾期数 | 与口径冻结表逐项一致 |
| S-02 | 热力图：日×周综合完成度分级配色；点击下钻 | 无数据日显示空；下钻到日统计 |
| S-03 | 周统计：近 8 周完成率折线（任务、目标两条线） | 数据与周口径一致 |
| S-04 | 本周任务分布：按目标、按标签 done/total | 与任务列表数据一致 |
| S-05 | 未完成任务清单（本周 due） | 可点击跳转任务 |
| S-06 | 热力图权重可配置（默认 0.5/0.5） | 修改后立即重算 |

## 5. 复盘（R）

| 编号 | 需求描述 | 验收标准 |
|---|---|---|
| R-01 | 周复盘列表按周倒序，显示该周综合完成度徽章 | 徽章取实时统计 |
| R-02 | Markdown 编辑器（源码/预览）；编辑自动保存草稿 | 刷新页面草稿不丢 |
| R-03 | 模板 = 统计快照段 + KPT + 下周计划；打开模板自动生成快照段 | 快照数字与实时统计一致 |
| R-04 | 快照冻结：保存后 JSON 不变；提供手动「刷新快照」 | 改任务数据后历史复盘不变 |
| R-05 | 删除周复盘（二次确认） | 不影响任务/目标数据 |
